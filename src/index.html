Telegram Auto-Backup Setup

1

Create your Telegram Bot

Open Telegram and search for @BotFather (or tap t.me/BotFather).

Tap Start, then send the command /newbot.

Choose a name (e.g. My Jezdan Backup) and a username ending in bot (e.g. my_jezdan_backup_bot).

BotFather will reply with your HTTP API Token — it looks like:
123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ

Copy this token. You will paste it in the settings.

2

Get your Chat ID

Search for @userinfobot on Telegram (or tap t.me/userinfobot).

Tap Start. It will immediately reply with your Id number (e.g. 987654321).

Copy this number.

3

Start your Bot

Search for the bot username you just created in Telegram and tap Start.

Important: The bot cannot send you messages until you start a conversation with it first!

4

Connect Jezdan

Paste the Bot Token and Chat ID into the settings fields above.

Tap Test Connection — you should immediately receive a test message on Telegram.

Save your settings. Every transaction will now automatically send a backup file to your Telegram chat! 🎉

💡

How to restore from Telegram

If your data is ever lost, open your Telegram chat with the bot. Download the latest .json file, then use the "⬆ Restore from Backup" button in Jezdan's settings to import it.
